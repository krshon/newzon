#NEWZON — AI-Driven News Aggregation & Bias Analysis Platform

NEWZON is a work-in-progress news aggregation platform focused on analyzing political bias and credibility of news articles using machine learning.

The project aims to combine web development and NLP-based models to help users better understand how news is framed and how reliable it may be, rather than only presenting headlines.

This repository currently contains an initial structure and limited files. More frontend, backend, and machine learning components will be added as development progresses.
