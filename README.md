# NEWZON

## AI-Driven News Aggregation & Bias Analysis Platform

A work-in-progress news aggregation platform built to explore how **machine learning and NLP** can be used to analyze **political bias** and **credibility** in news articles.

The project focuses on combining **NLP-based analysis** with frontend and backend systems to provide contextual insights beyond headlines, similar to real-world media intelligence platforms.


## Planned Features

* Political bias classification (Left, Right, Neutral)
* Credibility / truth score estimation using ML models
* News aggregation from external APIs
* Backend services for scalable processing
* Interactive sports and live-style sections
* Video content for users to consume
* NEWZON API that can be used across platforms


## Note
This project is under active development.
The repository does not yet reflect the complete implementation.
